# Ordered goals for the Ralph loop's `goals` suite. One line each; an iteration deletes a line
# only when that goal's done-criteria hold. The loop then runs the line's Done-check itself and
# rejects the iteration if it fails. Later goals assume earlier ones are done.
debt-commit-metadata: re-saving an Elasticsearch data directory keeps its shard commit metadata (history_uuid, translog_uuid with a matching translog, max_seq_no, local_checkpoint, max_unsafe_auto_id_timestamp) instead of writing fresh values, so Elasticsearch treats the shard history as continuous. Add a test in es-index/tests/disk_save.rs named resaving_keeps_commit_history that opens fixtures/es-9.5.5/data, saves it elsewhere, and compares the commit user data. Done-check: `cargo test -p es-index --test disk_save resaving_keeps_commit_history && scripts/cross_engine_rust.sh`
debt-read-from-segments: indices opened from a data directory are served from their Lucene segments instead of copying every document into memory (es-index disk.rs), and term/match/range/bool queries on them use postings, doc values and points instead of scanning sources (es-query). Add es-index/tests/disk_memory.rs proving opening a 20000-doc directory does not load all _source values. Done-check: `cargo test -p es-index --test disk_memory && cargo test -p es-mini --test disk_parity && cargo test -p es-mini --test fixture_parity`
