constant-score-boost: es-query parses `boost` on every query (parse.rs) but ignores it, so constant_score always scores 1.0. Apply it as Elasticsearch does: constant_score scores each match exactly `boost`; term, terms, match, range, ids, exists, wildcard, prefix and bool multiply their score by `boost` (default 1.0); a nested boost multiplies the outer one. Match real ES scores: compare against fixtures/expected where a fixture covers it, and verify the rest with verify-with-elasticsearch. Commit every change you make; leave no uncommitted edits. Add es-query tests named `boost_` (one per query type above). Done-check: `cargo test -p es-query boost_ && test $(grep -rc 'fn boost_' es-query | awk -F: '{s+=$2} END {print s}') -ge 9`
