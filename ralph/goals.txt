# Ordered goals for the Ralph loop's `goals` suite. One line each; an iteration deletes a line
# only when that goal's done-criteria hold. The loop then runs the line's Done-check itself and
# rejects the iteration if it fails. Later goals assume earlier ones are done.
api-field-caps: implement `GET|POST /_field_caps` and `/{index}/_field_caps` (the `fields` parameter with wildcards, and `index_filter` is optional) returning Elasticsearch's `{indices, fields}` shape with per-type `searchable`/`aggregatable`, over es-index mappings, in es-mini/src. It is about 2.2% of 90 days of weighted client traffic. Add tests in es-mini/src/field_caps_tests.rs named `field_caps_` prefixed. Done-check: `cargo test -p es-mini field_caps_`
api-by-query: implement `POST /{index}/_update_by_query` and `POST /{index}/_delete_by_query` (query body, `conflicts=proceed`, response `took`, `total`, `updated`/`deleted`, `batches`, `version_conflicts`, `failures`) using the existing search and write paths; scripts are out of scope, so reject a `script` with a clear error. About 2.3% of weighted client traffic. Add tests named `by_query_` prefixed in es-mini/src/by_query_tests.rs. Done-check: `cargo test -p es-mini by_query_`
api-scroll-pit: implement `?scroll=` on `_search`, `POST /_search/scroll` (and `/_search/scroll/{id}`), `DELETE /_search/scroll`, plus `POST /{index}/_pit`, `DELETE /_pit` and `pit` in the `_search` body, as in-memory snapshots with expiry. About 2.3% of weighted client traffic. Add tests named `scroll_` and `pit_` prefixed in es-mini/src/scroll_tests.rs. Done-check: `cargo test -p es-mini scroll_ && cargo test -p es-mini pit_`
api-search-template: implement `_search/template`, `/{index}/_search/template` and `_msearch/template` for inline `source` templates with `params` (mustache section/variable substitution only; `id` stored scripts are out of scope), reusing `_search` and `_msearch`. About 0.37% of weighted client traffic. Add tests named `search_template_` prefixed. Done-check: `cargo test -p es-mini search_template_`
api-node-stubs: implement single-node `GET /_nodes`, `/_nodes/{filter}` (nodes.info) and `GET /_nodes/stats`, `/_cluster/stats`, `/_cluster/settings` stubs with Elasticsearch's response shapes and es-mini's real node and index counts, because clients call nodes.info (2.1% of weighted traffic) at startup. Add tests named `node_info_` prefixed. Done-check: `cargo test -p es-mini node_info_`
