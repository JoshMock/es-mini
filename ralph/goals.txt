# Ordered goals for the Ralph loop's `goals` suite. One line each; an iteration deletes a line
# only when that goal's done-criteria hold. The loop then runs the line's Done-check itself and
# rejects the iteration if it fails. Later goals assume earlier ones are done.
esql-cold-after-write: ES|QL keeps a whole-index table between queries (Index::memo, 306135a/9cfcf37) and rebuilds it from scratch after any write, so the first ES|QL query after a write at 100k documents takes 585-680 ms (ralph/esql-cold.sh), about 2.5x what it took before the table existed, while warm queries take 5-20 ms. Make the table follow writes instead of being rebuilt: update, append or invalidate only the rows a write touches (or build only the columns a query reads, lazily), keeping results identical. Work as a measured loop like esql-perf-100k: read and append to ralph/PERF_NOTES.md, form one hypothesis at a time, and keep only changes that lower ralph/esql-cold.sh's numbers without slowing warm queries. Never edit bench/ or ralph/esql-cold.sh. Done-check: `ralph/esql-cold.sh`. Gate: `MIN_GAIN=1.02 bench/ab.sh $START`
search-memory-walk: after a bulk load es-mini keeps every document in memory (translog, no segments), and each search walks all of them: docs_at collects the 100k in-memory documents and sorts them by seq_no (es-index/src/lib.rs, now sort_by_cached_key), then search_many reads each one's seq_no, visibility and score. gdb samples of the server put nearly all of match_all's 41 ms (took) there; bench match_all and bool are 2-3x slower than Elasticsearch. Make searches over in-memory documents stop doing per-document work they do not need, matching Elasticsearch's results exactly: e.g. keep the in-memory documents in seq_no order as they are written instead of sorting per search, and when hits are ordered by a constant score with no aggregations, stop once the page is filled and total hits reach the track_total_hits limit (10,000 by default, reported as `gte`, as Elasticsearch does). Work as a measured loop like esql-perf-100k (ralph/PERF_NOTES.md; one hypothesis at a time; keep only changes ab.sh passes). Never edit bench/. Done-check: `ONLY='match_all|bool' MAX_MS=20 bench/ab.sh HEAD`. Gate: `ONLY='match_all|bool|range_sort|term|count' bench/ab.sh $START`
